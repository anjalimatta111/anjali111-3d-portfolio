# Anjali Matta AI

Create a premium 3D portfolio for Anjali Matta, a first-year B.Tech AI & Data Science student at JECRC University.

Use a light white background, soft blue/lavender gradients, glassmorphism, 3D AI visuals, smooth animations and modern typography.

Sections: Home, About, Education, Learning, Projects Coming Soon, Goals, Contact.

Hero CTA: “Explore My Portfolio” and secondary CTA “Let’s Connect”.

Keep it minimal, elegant, futuristic and student-friendly. Don’t add fake skills, projects or experience.
