# Anjali Matta 3D Portfolio

## Overview
Build a polished, responsive one-page portfolio at the home address for Anjali Matta. The experience will stay factual, use a luminous white-and-lavender visual system, and feature an interactive abstract AI network rather than stock imagery or invented achievements.

## Page structure
- Floating navigation linking to Home, About, Education, Learning, Projects, Goals, and Contact.
- Home: Anjali’s name, factual student introduction, both requested calls to action, and a full-bleed interactive 3D neural-network form.
- About: a concise first-year student profile without inferred skills or experience.
- Education: JECRC University and B.Tech in AI & Data Science, with the year framed only as “First year.”
- Learning: present the current learning journey without naming unprovided tools, languages, or competencies.
- Projects: an honest “Coming Soon” state with no fabricated project cards.
- Goals: forward-looking goals described without claiming accomplishments.
- Contact: a “Let’s Connect” area that invites contact without inventing an email address, phone number, or social profile.

## Visual and interaction direction
- Bright white canvas with soft blue/lavender washes, fine borders, restrained glass surfaces, and modern sans-serif typography.
- Abstract 3D AI constellation made from animated nodes, connections, rings, and a translucent core; pointer movement subtly changes its perspective.
- Smooth section entrances, gentle floating motion, responsive navigation, and reduced-motion support.
- Strong contrast and comfortable sizing across phone and desktop layouts.

## Technical details
- Use React Three Fiber and Drei for the 3D scene, mounted client-side to avoid server-rendering issues.
- Centralize semantic color, type, surface, and shadow tokens in the global design system.
- Keep the implementation in focused page and 3D visual files, with metadata specific to Anjali’s portfolio.
- Validate the live page in desktop and mobile-sized browser views, including clean runtime logs and a visible animated 3D scene.
